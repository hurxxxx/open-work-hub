# 과업 범위

## 1. 문서중앙화 시스템 연계

- 문서중앙화 시스템(mcloudoc) 연계 인터페이스 개발
- 문서 원문 및 기본 정보(제목, 작성자, 작성일, 부서, 문서 종류 등 메타데이터) 수집 기능 구현
- 신규·변경·삭제 문서에 대한 증분 동기화 기능 구현

## 2. PLM 연계

- PLM 연계 인터페이스 개발
- 품목, BOM, 도면, 관련 문서 등 주요 PLM 정보 조회 기능 구현
- PLM 메타데이터의 검색 및 질의응답 기능 연계 구현

## 3. RAG 통합 플랫폼 구축

- 문서 수집·전처리·색인 파이프라인 구축
- 벡터 데이터베이스 및 유사도 검색 인덱스 구축
- 전문검색(Full-text Search) 엔진 구축 및 검색 API 개발
- OCR 처리 연계 모듈 및 텍스트 추출 표준화 기능 개발
- 문서 내용을 의미 기반 검색에 활용할 수 있도록 문서 임베딩(문서 내용을 숫자 벡터로 변환하는 처리) 생성, 갱신 및 색인 연계 기능 개발
- 1차 검색 결과를 더 적합한 순서로 다시 정렬하는 재정렬(Re-ranking) 기능 개발
- 의미 기반 검색(벡터 검색)과 키워드 기반 검색(BM25 기반 전문검색)을 함께 활용하는 하이브리드 검색 API 개발
- 사용자 로그인과 접근 권한 관리를 구현하고, 역할 기반 접근통제(RBAC, Role-Based Access Control)를 적용
- 주요 기능별 REST API 제공 및 OpenAPI Specification 기반의 표준 API 명세서 작성

## 4. AI 포털 구축

- 사용자 인증 및 역할 기반 접근통제(RBAC) 권한관리 체계 적용
- 검색 포털형 UI 기반 문서 검색 기능 구현
- AI 포털 내 PLM 정보 조회 기능 구현
- 문서 및 PLM 데이터를 활용한 대화형 질의응답 인터페이스 구현
- 답변 근거, 출처 링크 및 권한 기반 응답 제어 기능 제공

## 5. 문서 작성 지원 기능

- 문서 템플릿 관리 기능 구현
- 보고서, 기술문서 등 용도별 템플릿 등록·수정·삭제 기능 구현
- 템플릿 내 자동 채움 영역 정의 기능 구현
- 사용자 질의 또는 주제 입력 시 관련 문서 및 PLM 데이터를 검색하여 문서 초안을 자동 생성하는 기능 구현
- RAG 검색 결과 기반 LLM 문서 초안 생성 기능 구현
- 생성 문서에 출처 및 근거 정보 포함 기능 구현
- 포털 내에서 생성된 초안을 확인·수정할 수 있는 검토 및 편집 인터페이스 구현
- 생성 문서를 docx, PDF 등 형식으로 출력 및 다운로드하는 기능 구현

## 6. 개발 및 사업관리 환경 구성

- 소스코드와 변경 이력을 관리하기 위한 Git 기반 형상관리 환경 구성
- PMS 기반 프로젝트 관리 체계 적용
- Wiki 기반 지식 관리 체계 적용

## 7. 인프라 구성

- RAG 플랫폼 운영을 위한 애플리케이션·검색·배치 서버 환경 구성
- GPU 기반 LLM 추론 및 서빙 서버 환경 구성
- 로그, 모니터링, 백업 및 운영 지원 환경 구성

# 검수 기준

## 1. 문서중앙화 시스템 연계

- 연계 대상 문서가 정상 수집될 것
- 문서 메타데이터가 검색 서비스에 정상 반영될 것
- 신규·변경·삭제 문서에 대한 증분 동기화가 정상 수행될 것
- 문서 권한정보가 검색 결과 및 응답 서비스에 반영될 것

## 2. PLM 연계

- 정의된 PLM 조회 대상 정보가 정상 조회될 것
- 조회 결과가 포털 및 챗봇 기능과 연계될 것
- 사용자 권한에 따라 접근 가능한 정보만 제공될 것

## 3. RAG 통합 플랫폼

- 수집·전처리·색인 파이프라인이 정상 동작할 것
- 전문검색, 벡터 검색, 하이브리드 검색 기능이 정상 제공될 것
- 재정렬 기능이 검색 결과 품질 개선에 반영될 것
- OCR, 임베딩, 색인 기능이 정의된 처리 흐름에 따라 동작할 것
- API가 명세서에 따라 정상 제공될 것
- 사용자 인증 및 RBAC 기반 권한관리가 정상 동작할 것

## 4. AI 포털

- 로그인 및 권한별 메뉴 제어가 가능할 것
- 검색어 입력, 필터, 결과 목록, 상세 보기 기능이 제공될 것
- PLM 조회 기능이 포털 내에서 정상 동작할 것
- 챗봇 응답 시 문서 또는 PLM 기반 근거 정보가 제시될 것
- 근거가 불충분한 경우 제한 응답 또는 예외 처리 정책이 적용될 것

## 5. 문서 작성 지원 기능

- 문서 템플릿의 등록·수정·삭제가 가능할 것
- 템플릿 내 자동 채움 영역 설정이 가능할 것
- 사용자 질의 또는 주제 입력 시 관련 문서 및 PLM 데이터를 기반으로 문서 초안이 생성될 것
- 생성 문서에 출처 및 근거 정보가 포함될 것
- 생성된 초안에 대해 포털 내 검토 및 수정이 가능할 것
- 생성 문서를 docx, PDF 등 정의된 형식으로 다운로드할 수 있을 것

## 6. 개발 및 사업관리 환경

- Git 저장소 및 형상관리 체계가 적용될 것
- PMS를 통한 일정, 이슈, 진척 관리가 가능할 것

## 7. 인프라 및 운영

- 서버 구성 내역이 문서화될 것
- 로그 및 모니터링 기능이 제공될 것
- 배포 및 운영 절차가 문서화될 것
- 운영자 매뉴얼 및 관련 산출물이 제출될 것

## 8. 산출물

- 시스템 구성도 및 연계 구조도
- 기능별 인터페이스 명세서(API 명세 포함)
- 시험 결과서
- 운영자 매뉴얼(배포·운영 절차 포함)
- 최종 결과보고서
