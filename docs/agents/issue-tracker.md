# Issue Tracker

Open Work Hub의 이슈는 GitHub 저장소 `hurxxxx/open-work-hub`의 GitHub Issues에서 관리한다.
원격 저장소가 바뀔 수 있으므로 작업 전에 `git remote -v`로 대상을 확인한다.

사용자가 이슈 생성·조회·수정을 요청한 경우 인증된 GitHub CLI를 사용한다. 읽기 작업은
`gh issue list`와 `gh issue view`, 변경 작업은 `gh issue create`, `gh issue edit`,
`gh issue comment`, `gh issue close`를 사용한다. 이슈 변경은 외부 상태를 바꾸므로 요청 없이
실행하지 않는다.

오래 유지할 구현 결정은 이슈 댓글에만 남기지 않는다. 해당 계약을 소유하는
`docs/domains/`, `docs/apps/`, `docs/product/` 문서나 루트 `adr/`의 accepted ADR을 갱신하고
이슈에서 링크한다. 시크릿, 운영 데이터, 고객 문서와 민감한 로그는 이슈 본문·댓글·첨부에
넣지 않는다.

AI가 생성한 triage 또는 agent brief 댓글은 다음 문구로 시작한다.

```markdown
> *This was generated by AI during triage.*
```
