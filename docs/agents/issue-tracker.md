# Issue Tracker

- Canonical tracker: GitLab `gitlab.1punicorn.com/lumejs/open-work-hub`.
- GitHub is source upstream, not site tracker.
- Use `glab` for live issue reads/writes.
- Read-only issue commands are allowed when requested.
- Creating/updating issues, comments, labels, state, or closures requires explicit user authorization.
- Durable decisions belong in owner docs or root `adr/`; issues link to them.
- Never put secrets, `.env` values, customer data, raw logs, raw prompts, or sensitive attachments in issues.

AI triage comments start with:

```markdown
> *This was generated by AI during triage.*
```
