# PMS App Docs

PMS는 Open Work Hub가 직접 소유하는 업무 추적 앱이다. 스페이스, 폴더, 리스트, 태스크를 기준으로 팀 업무를 운영하고 Docs, Whiteboard, Planner, Meeting, AI 보조 흐름과 연결된다.

## 문서

- [PMS 런타임 도움말](../../../apps/web/public/help/pms/user-guide.html): Help Center에서 제공하는 사용자용 HTML 가이드 정본.

PMS 사용자 매뉴얼은 이 폴더에 별도 초안으로 복제하지 않는다. 사용자 가이드를 수정해야 하면 런타임 도움말 파일을 먼저 갱신한다.

AI 기반 PMS 쓰기 동작의 승인 기준은 [AI Write Policy](../../domains/ai/write-policy.md)를 본다.
