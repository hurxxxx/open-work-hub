# 중요
## 이 파일을 LLM이 수정할 때는 절대로 의도나 맥락을 변경해서는 안 된다.

# 아이디어
- LLM이 사용자 전면에 나설 필요는 없다. AX는 곧 AI가 전면에 나서 사용자 대신 업무를 수행하는 시스템을 구축하는 것이라고 오해할 수 있다.
- 그러나 AI가 전면에 나서지 않더라도, 사용자를 위한 업무 시스템의 개발과 혁신을 AI를 통해 저비용·고효율로 달성할 수 있는 환경을 구축하는 것 또한 AX의 한 부분이라고 생각한다.
- AX를 위해서는 외부 LLM의 활용이 필수적이다.
- 그러므로 내부 업무 시스템은 내부에 구축한 SLM을 활용하되, AX를 위한 내부 협업 및 수행 인력은 외부 초거대 모델을 사용할 수 있어야 한다.
- 향후 전사 확산시 이점이 고려되어햐 한다.
