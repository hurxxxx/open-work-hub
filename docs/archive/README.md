# Archive

이 디렉터리는 유지가 명시적으로 승인된 비계획 참고자료만 두며, 현재 작업 컨텍스트에서는 제외한다.

과거 개발 계획, 로드맵, TODO, 진행 이력 문서는 혼선을 줄이기 위해 저장소 정본
문서로 보존하지 않는다. 원문이 필요하면 사용자가 명시했을 때 Git 이력에서 복원한다.

규칙:

- 사용자가 명시적으로 요청한 경우에만 읽는다.
- 현재 구현 기준, 작업 지시, 에이전트 기본 컨텍스트로 사용하지 않는다.
- 현재에도 유효한 결정은 `docs/current/`, `docs/domains/`, `docs/apps/`, ADR로 승격한다.
- 완료된 조사 로그와 날짜 고정 사용량 스냅샷은 결론만 소유 문서에 반영하고 원문은 Git 이력에서 복원한다.
