# 11. 아이디어에서 출시까지

> **한 줄 요약.** AI 기능도 일반 서비스처럼 아이디어, 대상, 데이터, 화면, API, 테스트, 출시, 운영의 흐름을 거쳐야 한다.

## 업무 상황

“메일 초안 작성 기능”을 떠올렸다고 바로 개발할 수는 없습니다. 누가 쓰는지, 어떤 메일을 대상으로 하는지, AI가 어떤 자료를 참고해야 하는지, 초안 이후 사람이 어디서 수정하고 승인하는지 정해야 합니다.

## 핵심 개념 3개

| 개념 | 설명 |
| --- | --- |
| MVP | 처음부터 완벽하지 않아도 핵심 가치만 검증하는 최소 기능 |
| 데이터 설계 | 화면과 업무에서 필요한 정보를 저장 구조로 옮기는 일 |
| 출시 기준 | 사용자가 쓸 수 있다고 판단하는 최소 품질 기준 |

## 작동 흐름

| 단계 | 질문 | 산출물 |
| --- | --- | --- |
| 아이디어 | 어떤 문제를 줄이나 | 문제 정의 |
| MVP | 가장 작은 기능은 무엇인가 | 범위표 |
| 화면 | 사용자는 어디서 누르나 | 화면 흐름 |
| 데이터/API | 무엇을 저장하고 주고받나 | 데이터/API 초안 |
| 테스트 | 무엇이 맞으면 통과인가 | 검수 시나리오 |
| 출시/운영 | 누가 문의를 받고 개선하나 | 운영 기준 |
