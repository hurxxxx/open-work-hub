# 05. RAG와 근거 기반 답변

> **한 줄 요약.** RAG는 AI가 기억으로 답하는 대신, 현재 회사 문서를 찾아 그 근거를 붙여 답하게 만드는 구조다.

## 오늘의 흐름

질문은 바로 LLM으로 가지 않고, 먼저 관련 문서를 찾은 뒤 근거와 함께 답변으로 이어집니다.

## 업무 상황

현업 사용자가 “지난 설계 변경에서 반복된 문제를 알려 줘”라고 묻는다면 모델의 일반 지식은 도움이 되지 않습니다. AI-Doo는 사내 문서, 회의록, PLM 메타데이터를 찾아야 하고, 답변에는 어떤 문서를 근거로 삼았는지 보여 줘야 합니다.

## 핵심 개념 3개

| 개념 | 설명 |
| --- | --- |
| 검색 | 질문과 관련된 문서 후보를 찾는 단계 |
| 근거 | 답변에 사용된 실제 문서 조각 |
| 인용 | 사용자가 원문을 확인할 수 있게 출처를 붙이는 방식 |

## 작동 흐름

| 단계 | 무엇을 하는가 | 실패하면 생기는 문제 |
| --- | --- | --- |
| 질문 이해 | 사용자가 무엇을 찾는지 파악 | 엉뚱한 검색어가 만들어짐 |
| 문서 검색 | 관련 후보 문서를 찾음 | 중요한 근거가 누락됨 |
| 근거 선별 | 답변에 쓸 조각을 고름 | 오래되거나 권한 없는 문서가 섞임 |
| 답변 생성 | 근거 기반으로 문장을 만듦 | 그럴듯하지만 틀린 답이 나옴 |
| 출처 확인 | 사용자가 원문을 확인 | 신뢰할 수 없음 |
