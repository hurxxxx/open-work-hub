# 01. AI 시대 협업과 좋은 요청

> **한 줄 요약.** 좋은 AI 활용은 “멋진 프롬프트”가 아니라 목표, 배경, 대상, 제약, 검수 기준을 분명히 주는 업무 협업 방식이다.

## 오늘의 흐름

사람이 목표와 맥락을 주고, AI가 초안을 만들고, 사람이 검수 기준으로 확인한 뒤 다시 수정 요청합니다.

## 업무 상황

허건우책임이 “PLM 자료를 AI-Doo에서 검색되게 해 주세요”라고만 요청하면 범위가 너무 넓습니다. AI는 무엇이 중요한지 모릅니다. 반대로 “품번, BOM, 도면 변경 사유를 우선 검색하고, NDA 자료는 외부 API로 보내지 말고, 결과에는 출처 링크를 붙여야 한다”라고 주면 작업이 훨씬 안전해집니다.

## 핵심 개념 3개

| 개념 | 설명 |
| --- | --- |
| 목표 | 무엇을 끝내면 성공인지 한 문장으로 말한다 |
| 맥락 | 왜 하는지, 누가 쓰는지, 어떤 데이터가 있는지 알려 준다 |
| 검수 기준 | 결과를 보고 맞다/아니다를 판단할 기준을 먼저 둔다 |

## 작동 흐름

| 단계 | 사람이 하는 일 | AI가 하는 일 | 검수 포인트 |
| --- | --- | --- | --- |
| 요청 | 목표와 제약을 쓴다 | 초안 방향을 잡는다 | 빠진 조건이 없는가 |
| 초안 | 결과를 읽는다 | 문서, 표, 계획을 만든다 | 업무 목적에 맞는가 |
| 수정 | 틀린 부분과 원하는 방향을 말한다 | 다시 작성한다 | 같은 실수를 반복하지 않는가 |
| 확정 | 승인하거나 다음 작업으로 넘긴다 | 보조 역할을 끝낸다 | 책임자가 확인했는가 |

```text
문서 검색 챗봇 만들어 줘.
```

## 회상 질문
