# Interface Design

Use after user selects one architecture candidate.

## Process

1. State constraints, dependency categories, and a small illustrative sketch.
2. Produce up to three different interfaces:
   - minimum surface
   - maximum flexibility
   - easiest common caller
3. For each design include interface, usage, hidden implementation, dependency/adapters, trade-offs.
4. Compare by depth, locality, seam placement.
5. Recommend one or hybrid.
