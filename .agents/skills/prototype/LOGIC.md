# Logic Prototype

Use for state machine, business logic, or data-shape questions.

## Shape

- State the exact question in README/comment.
- Use project runtime/tooling.
- Keep core logic pure and portable: reducer, state machine, pure functions, or small module.
- TUI is a thin throwaway shell.
- Render current state plus shortcuts each tick; fit one screen.
- One command to run.

## Rules

- No tests.
- No real DB unless persistence is the question.
- No generalization beyond the question.
- Delete shell when done; keep only validated decision.
