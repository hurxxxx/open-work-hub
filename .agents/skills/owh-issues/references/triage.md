# Triage

Use GitLab Issues, `docs/agents/issue-tracker.md`, `docs/agents/triage-labels.md`, and `glab`. External mutations require explicit authorization.

AI triage comments start:

```markdown
> *This was generated by AI during triage.*
```

## Labels

- `bug`: confirmed/plausible defect.
- `needs-triage`: missing evidence/scope/maintainer decision.
- `ready-for-agent`: complete brief; no unresolved decision.

Check live labels before changes:

```bash
glab label list --per-page 100
```

## Flow

1. `glab issue view` full issue/comments/labels/reporter/dates.
2. Inspect code/tests/docs/ADRs.
3. Reproduce safely for bugs.
4. Recommend label/readiness/closure with evidence.
5. Mutate only if requested.

Ready: post [AGENT-BRIEF.md](../AGENT-BRIEF.md), remove `needs-triage`, add `ready-for-agent`. Unresolved: keep/add `needs-triage`. Duplicate/rejected: comment reason and close only when authorized.
