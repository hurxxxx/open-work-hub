# Issue Workflow

Use GitLab origin, [issue ownership](../../../docs/agents/issue-tracker.md), and [current labels](../../../docs/agents/triage-labels.md).

Choose the requested artifact:
- Product requirements: [prd.md](references/prd.md).
- Independent vertical implementation slices: [slices.md](references/slices.md).
- Existing issue evidence/readiness: [triage.md](references/triage.md) and [AGENT-BRIEF.md](AGENT-BRIEF.md).

Draft from the conversation and current code. Ask only about consequential missing decisions. Preserve unresolved items explicitly; ready-for-agent requires a complete brief.
Publish or change issue state only when that action is requested. An existing publication instruction is authorization; do not ask again merely because a draft is now ready. Do not automatically change parent issues.
