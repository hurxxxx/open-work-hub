# Agent Brief

Use as GitLab issue comment.

```markdown
> *This was generated by AI during triage.*

## Agent brief

**Summary:** required outcome

**Current behavior:** current evidence/repro

**Desired behavior:** observable result and edge/error cases

**Contract constraints:**

- owner doc/ADR/interface/auth/audit/migration/compatibility rule

**Acceptance criteria:**

- [ ] externally verifiable criterion
- [ ] relevant automated check/test
- [ ] docs/migration contract updated when applicable

**Out of scope:**

- adjacent behavior not changed

**Validation:**

- command/check
```

Labels: `bug` for defects, `needs-triage` while decisions/evidence are missing, `ready-for-agent` only when brief is complete.
