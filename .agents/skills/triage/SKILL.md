# Triage

Use GitLab Issues for `dwdcc/ai-do` and the contract in `docs/agents/triage-labels.md`. Use `glab`; do not substitute GitHub commands or invent labels.

Every triage or agent-brief comment posted to an issue must start with:

```markdown
> *This was generated by AI during triage.*
```

## Labels and state

- `bug` is an optional defect marker. Feature work has no category label.
- `needs-triage` means evidence, scope, or a maintainer decision is unresolved.
- `ready-for-agent` means an AFK agent can implement the issue from its brief without hidden decisions.
- An issue must never carry both state labels. Applying one removes the other.
- A reopened issue returns to `needs-triage` until its brief is revalidated.

Verify the live labels with `glab label list --per-page 100` before changing the documented vocabulary.

## Review issues needing attention

Show unlabeled and `needs-triage` issues oldest first. Summarize the title, existing labels, last activity, and the unresolved decision or missing evidence. Do not treat closed issues as active work.

## Triage one issue

1. Read the issue body, comments, labels, reporter, and dates.
2. Inspect current code, tests, owning documents under `docs/current`, `docs/domains`, or `docs/apps`, and relevant accepted ADRs in root `adr/`.
3. For a bug, attempt a safe reproduction and report the exact result.
4. Recommend either `needs-triage`, `ready-for-agent`, or closure, with evidence.
5. Apply the outcome only when the user's request authorizes changing the issue.

Outcomes:

- **`ready-for-agent`**: post a complete brief using [AGENT-BRIEF.md](./AGENT-BRIEF.md), remove `needs-triage`, and add `ready-for-agent`.
- **Still unresolved**: keep or add `needs-triage`, remove `ready-for-agent`, and comment with confirmed facts plus specific unanswered questions.
- **Duplicate or rejected**: comment with the reason and any canonical issue/doc link, remove both state labels, and close.

Do not invent additional category/state labels or create a parallel rejection archive.
