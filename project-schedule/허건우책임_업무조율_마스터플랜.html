1-1. 허건우책임 실행 태스크 — W1/W2

마스터 플랜은 그대로 두고, 실제 진행을 위해 허건우책임이 챙길 일과 현업에 요청할 일을 주차별로 분리 관리.

W1 (05/11~05/15) — 대상 부서 후보·데이터 현황 파악

항목 허건우책임 현업 요청 전달 문구
문서중앙화 RAG · 문서중앙화 RAG PoC 방향과 기본 아키텍처 초안 정리
· 샘플 문서 기반 테스트 범위와 품질 확인 항목 정의
· 초기 RAG 구성 후보와 테스트 계획 정리 		· 성능 및 품질 테스트에 사용할 실제 업무 문서 샘플 준비 RAG 장비를 활용하여 실제 업무 문서 샘플로 여러 가지 검색·응답 품질 테스트를 수행하고, 가장 적합한 구성 조합을 찾는 작업을 진행할 예정입니다.
PLM 연동 · PLM 측 진행상황 확인 및 대기
· 향후 분석에 필요한 샘플 데이터 항목 정리 		· PLM 연동 검토용 샘플 데이터를 준비해 주세요. PLM 연동은 3주차까지 PLM 측 진행상황을 기다리며, 우선 테스트 가능한 샘플 데이터 확보 여부를 확인합니다.

W2 (05/18~05/22) — 1순위 부서 확정·샘플 데이터 인수

항목 허건우책임 현업 요청 전달 문구
문서중앙화 RAG · RAG 아키텍처와 테스트 환경 구성
· 샘플 문서 수집 후 전처리·인덱싱 테스트 수행
· 검색 정확도, 응답 품질, 근거 표시 수준 확인
· 테스트 결과를 바탕으로 개선 방향과 다음 주 작업 범위 정리 		· 실제 업무에서 사용할 문서 샘플 제공
· 문서별 기본 설명과 사용 맥락 공유
· 샘플 문서로 확인하고 싶은 대표 질문 제공

PLM 연동 · 제공받은 샘플 데이터 기준으로 구조와 주요 항목 분석
· 향후 검색·연동 가능성 검토 		· PLM 연동 검토용 샘플 데이터를 준비해 주세요. PLM 본 연동은 진행상황을 기다리되, 샘플 데이터가 확보되면 먼저 데이터 구조를 분석해 향후 연동 방향을 검토하겠습니다.
