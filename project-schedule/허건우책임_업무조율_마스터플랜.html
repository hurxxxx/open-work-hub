1-1. 허건우책임 실행 태스크 — W1/W2

마스터 플랜은 그대로 두고, 실제 진행을 위해 허건우책임이 챙길 일과 현업에 요청할 일을 2주 단위로 분리 관리.
마스터 플랜은 변동 가능성이 크므로 세부 실행 태스크는 2주 단위 스프린트 변경 형태로 운영한다. 각 스프린트는 항목별 전주 실적 / 금주 진행상황 / 차주 계획 / 현업 요청사항 기준으로 정리하며, 현재 W1은 시작 주차이므로 전주 실적은 없음.
