홈페이지의 데이터 시각화 화면을 화면 구성·버튼 그대로 재현했습니다. 각 버튼에 번호(빨간 배지)를 달아 두었고, 화면 아래 범례에서 번호별 의미를 설명합니다.

1. 데이터 시각화 홈 (구성)

데이터 시각화는 실차 · 시스템 · 컴프(성능/신뢰성)로 구성됩니다. 홈에서 시험 유형을 선택해 들어갑니다.

2. 시스템 성능

시스템 평가 데이터를 업로드 → 매칭 → 표/그래프/선도 → DB화하는 7개 탭으로 구성됩니다. 먼저 상단 탭과 파일 업로드 화면입니다.

목적 시스템 성능 시험 후 원인분석·사양 변경사항을 반영한 데이터베이스를 구축합니다.
